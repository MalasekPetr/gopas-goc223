# Den 1 — Onboarding, prostředí, mapa API a strategie

Onboarding do sdíleného GA tenantu a pravidla práce, připravený a **ověřený** toolchain,
mapa API nad M365 a SPO s prvním hands-on v Graph Exploreru, vývojářské prostředí a návyky,
a rozhodovací rámec „který automatizační nástroj kdy".

| Pořadí | Blok | Slug | Typ |
|---|---|---|---|
| 1 | Onboarding & pravidla práce | [`onboarding`](onboarding/) | P |
| 2 | Toolchain skriptera: PowerShell 7, Node a CLI | [`toolchain-setup`](toolchain-setup/) | P |
| 3 | Mapa API nad M365 a SPO | [`api-landscape`](api-landscape/) | P |
| 4 | Inženýrské prostředí, VS Code a Copilot | [`vscode-copilot-env`](vscode-copilot-env/) | P |
| 5 | Strategie automatizace & nástrojová mapa | [`automation-strategy`](automation-strategy/) | P |

**Nejhustší den kurzu (~6,3 h povinně).** Linka dne je „od účtu k prvnímu vlastnímu volání
API": bloky 1-2 udělají účet a stroj
připravené, blok 3 dá rozhodovací rámec a **první hands-on** (cvičení Graph Explorer),
blok 4 pracovní návyky a repozitář, blok 5 nástrojovou osu a app registraci.

> [!NOTE] Nástrojová mapa ([`automation-strategy`](automation-strategy/)) zavádí app
> registration/identity strategii, na kterou hned ráno dne 2 navazuje
> [`../day-2/powershell-deep-dive/`](../day-2/powershell-deep-dive/) konkrétní implementací
> autentizace a prvním velkým labem.

> [!IMPORTANT] Co se smí zkrátit při skluzu onboardingu
> Blok 2 na předinstalované učebně (35 min místo 45). Pak výklad bloku 3.
> **Cvičení Graph Explorer se neškrtá** — je to jediný okamžik dne, kdy student něco sám
> udělá, a lab bloku 4 lze podle času dokončit ráno dne 2.
